# Prompt basis

## Reusable template

Replace the bracketed fields with the requested subject and one purpose cue.
Keep the prompt focused; do not add every possible bot feature.

```text
Create a square chat bot avatar for [bot name and purpose]. Minimal flat graphic:
[one rounded silhouette, a few large facial features, and one integrated cue].
Solid deep navy background, warm off-white primary shape, mint-green accent.
Flat vector-like raster illustration, only three solid colors, no gradients,
no shadows, no texture, no circuitry, no charts, no decorative details, no text.
Exceptionally simple and instantly legible at 32x32 pixels. Centered, generous
safe margins for circular cropping. Bold shapes, clean negative space, friendly
and confident expression.
```

## Variation directions

Keep the same palette and simplicity while varying one concept:

- A rounded speech bubble with one large checkmark: the clearest reply metaphor.
- A robot with a dot eye and a checkmark eye: personality without an extra badge.
- A smiling speech bubble: approachable and conversational.
- A robot visor containing one large mark: a bold face with minimal features.

Use only cues that fit the bot's actual purpose. A successful-fix checkmark is
appropriate for Data Alert Replies, not a mandatory symbol for every avatar.
